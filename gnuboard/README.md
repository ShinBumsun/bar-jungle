# BAR JUNGLE — 그누보드5 테마

정적 사이트(`/index.html`)를 그누보드5 테마로 옮긴 것입니다.
화면과 동작은 정적 버전과 동일하며, 메뉴·주소 같은 내용만 PHP 데이터 파일로 분리했습니다.

## 설치

1. 그누보드5를 설치한 뒤, `theme/bar-jungle` 폴더를 그누보드 루트의 `theme/` 아래에 업로드합니다.

   ```
   /그누보드루트/theme/bar-jungle/
   ```

2. 관리자 → **디자인 → 테마** 에서 `BAR JUNGLE` 을 선택하고 적용합니다.

3. 관리자 → **환경설정 → 기본환경설정** 에서
   - 모바일 사용 여부는 켜 두어도 됩니다. 반응형 테마라 모바일도 같은 파일을 씁니다.
   - 사이트 제목을 `BAR JUNGLE 바 정글` 로 넣으면 `<title>` 에 반영됩니다.

요구 사항은 그누보드 **5.4 이상**, PHP **5.6 이상**(7.x · 8.x 권장)입니다.

## 폴더 구조

```
theme/bar-jungle/
├── theme.config.php      테마 정보 (관리자 화면에 표시)
├── index.php             메인 페이지. 여기서 data/*.php 를 읽어 들입니다
├── head.sub.php          <!DOCTYPE> ~ <body> : meta · 오픈그래프 · 파비콘 · CSS
├── head.php              SVG 원본 도형 · 깊이 인디케이터 · 헤더(로고/GNB/언어전환)
├── tail.php              푸터 + 스크립트
├── tail.sub.php          </body></html>
├── data/
│   ├── menu.php          메뉴 208종  ← 메뉴 수정은 여기
│   └── site.php          주소 · 영업시간 · 인스타 주소  ← 매장 정보 수정은 여기
├── lib/jungle.lib.php    도수 표시 등 테마 전용 함수
├── css/                  init.css · layout.css
├── js/                   i18n.js(3개 국어 사전) · lib.js(동작)
├── img/                  로고 · 파비콘 · 오픈그래프 · moment 사진
└── mobile/               반응형이라 PC 파일을 그대로 include
```

## 내용 수정하는 곳

| 바꿀 것 | 파일 |
|---|---|
| 메뉴 항목 · 가격 · 도수 · 설명 | `data/menu.php` |
| 주소 · 영업시간 · 인스타그램 주소 | `data/site.php` |
| 영어 · 일본어 문구 | `js/i18n.js` |
| 히어로 · 소개 · 시그니처 문구 | `index.php` |
| 사진 | `img/moment/m1~m6.jpg` 교체 |

`data/menu.php` 의 한 줄은 이런 형태입니다.

```php
array('ko'=>'정글쥬스', 'en'=>'Jungle Juice', 'price'=>'13,000', 'alc'=>3, 'desc'=>'데킬라, 진과 …'),
```

- `alc` 는 도수 0~5. 0 이거나 빼면 점이 표시되지 않습니다.
- `vol` 을 넣으면 이름 옆에 용량(700ml)이 붙습니다. 보틀 메뉴에서 씁니다.
- `desc` 는 한국어만 있어 영어 · 일본어에서는 숨겨집니다.

## 아직 안 한 것

- **게시판 스킨** 은 넣지 않았습니다. 공지사항이나 예약 게시판이 필요하면 그때 만듭니다.
- 메뉴를 관리자 화면에서 고치려면 게시판이나 전용 관리 페이지가 필요합니다.
  지금은 `data/menu.php` 파일을 직접 고치는 방식입니다.
- 오픈그래프 이미지 주소는 **접속한 도메인 기준으로 자동 생성**되므로 따로 고칠 것이 없습니다.

## 로컬에서 미리 보기

호스팅 전에 확인하려면 PHP 내장 서버로 됩니다.

```bash
cd 그누보드루트
php -S 127.0.0.1:8080
```
